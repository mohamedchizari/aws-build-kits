# Review summaries

Two summaries are published here: `round4/FINDINGS_round4.md` and `round5/FINDINGS_round5.md`. They were written by the Claude session that coordinated the review, from the readers' and fixers' reports and its own runs.

Those reports, the readers' attack suites, the rehearsal transcripts and label files, and the emulator harness are not in this repository. Where a summary says "in this folder" or names a file under `_review_reports/` that is not here, it means the private folder it was written in.

Each kit's own `REVIEW_NOTES_r4.md` and `REVIEW_NOTES_r5.md` are published with the kit and list, finding by finding, what its fixer changed.
